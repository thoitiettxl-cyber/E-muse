# docs/decisions

Biên bản quyết định kiến trúc (ADR) của E-Muse — theo khung workflow mặc định
của repo (xem `~/AGENTS.md` mục "Repository workflow default").

## Quy ước

- Đánh số thứ tự: `0001-<ten-ngan>.md`, `0002-...`.
- Mỗi ADR ghi: **ngữ cảnh** (vì sao phải quyết), **quyết định** (chọn gì),
  **hệ quả** (đánh đổi, việc tiếp theo).
- Chỉ ghi quyết định kiến trúc / reliability / security / quality boundary —
  không ghi log việc vặt.
- Quyết định bị thay thế: giữ file cũ, thêm dòng "Superseded by NNNN" ở đầu,
  không xóa lịch sử.
